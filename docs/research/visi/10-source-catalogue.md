# VISI sources on the web (catalogue)

Public VISI sources used in these notes, with what each holds and whether a cloud session
can read it. Checked 2026-11-06. Links only; nothing was copied.

## Used in these notes

Hexagon's own help and training material, including third-party uploads of it, is not used.

| Source | What it holds |
| --- | --- |
| Hexagon product pages: [Mould](https://hexagon.com/products/visi-mould), [Progress](https://hexagon.com/products/visi-progress), [Analysis](https://hexagon.com/products/visi-analysis), [Electrode](https://hexagon.com/products/visi-electrode-design) | Feature lists with screenshots |
| VISI release history: <https://hexagon.com/products/product-groups/computer-aided-manufacturing-cad-cam-software/visi/release-history> | 2023.1 and 2024.3 changes only |
| Nexnet (Czech reseller) pages: <https://visi.nexnet.cz/visi-modelling.html> and siblings (mould, electrode, flow, progress, blank, multi-slides, machining 2D/3D/5-axis, PEPS-Wire), analysis video page <https://visi.nexnet.cz/visianalysis-video.html> | Feature descriptions, analysis tool list |
| r/VISI_CAD mirror: <https://r.datuan.dev/r/VISI_CAD/> | VISI API (VBA/Python) tips: `VISIPick` with `Filter` and `MoreElements` for multi-select; menu files (.mnu) for custom commands. Useful later if we want VISI file import or macros |
